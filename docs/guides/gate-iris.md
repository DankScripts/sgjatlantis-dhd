# Pegasus Gate Iris

The Atlantis Pegasus Iris Shield is installed on a **gate**, not around the city. For the separate city-wide shield addon, use the [City Shield wiki](https://dankscripts.github.io/sgjatlantis-cityshield/).

## Installation and removal

* **SGJourney:** use the shield item on a compatible gate controller that supports an iris. To remove an installed Atlantis iris, sneak-use the shield item on that controller.
* **Native Lantea:** use the shield item on the controller or a connected gate part. To remove it, sneak-use the shield item on the controller or gate part. The server message directs you to an Atlantis DHD to control the installed iris.

Use the shield control on the Atlantis DHD's gate display to open or close a supported installed shield. Do not confuse using the item to install or remove the iris with operating it.

On an SGJourney Pegasus gate, the Atlantis shield consumes **1,200 FE per tick while closed** from available gate/table buffered power. It cannot remain closed if insufficient power is available. That figure describes the SGJourney shield helper; do not assume the native Lantea implementation uses the same power rules.
