# Atlantis

Atlantis adds a bundled city, an Atlantis-style Stargate dialer, a Pegasus gate iris, transporters, jumper-bay controls, doors, power components and themed building pieces to Stargate Journey. Optional Lantea compatibility lets selected Atlantis controls work with Lantea's separate gate and puddle-jumper systems.

## What is covered

This guide covers the selected **2.0.5 Forge 1.20.1 and NeoForge 1.21.1 jars and the source archives distributed alongside them**. Other files carrying the same version number may differ. Mechanics below were checked against those source archives; they have **not all been verified in game**. Screens, recipes and behavior may differ in other releases or with other versions of dependencies.
