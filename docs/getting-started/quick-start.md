# Quick Start

1. [Install]({{ '/getting-started/installation.html' | relative_url }}) compatible Atlantis and Stargate Journey builds. Check the `SGJ Atlantis` creative tab for Atlantis components.
2. The bundled city is in Stargate Journey's `sgjourney:lantea` dimension. City chunks are processed as they load; see [Atlantis city]({{ '/guides/city.html' | relative_url }}) before changing or rebuilding anything.
3. Right-click the Atlantis DHD to dial; sneak-right-click it to open Crystal Controls. Player-placed tables need crystals and a working power supply. See the [DHD guide]({{ '/guides/dhd.html' | relative_url }}).
4. To travel between complete transporters, enter one, use its panel or map, and pick an available destination. See [transporters]({{ '/guides/transporters.html' | relative_url }}).
5. To operate the city's two jumper-bay openings, use their powered table or correctly placed redstone ports. These are fixed city openings, not arbitrary build-anywhere hatches.

{: .warning }
`/sgjatlantis city install` is a destructive rebuild, not a harmless refresh. Back up the entire world before using it.
