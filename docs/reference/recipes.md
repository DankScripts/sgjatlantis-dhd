# Recipes and Items

This catalog lists **every Atlantis recipe packaged** in the selected Forge 1.20.1 and NeoForge 1.21.1 version 2.0.5 jars, including the recipes restored in the locally built NeoForge 2.0.5-hotfix1. A packaged recipe is not a guarantee it loads in every installation: dependency versions, item aliases, tags and datapacks can affect it. These definitions were checked against the jars, not all crafted in-game. Check JEI or another recipe viewer in your installation.

{: .warning }
**NeoForge 2.0.5 is missing 14 recipes**, including the Atlantis DHD. The locally built 2.0.5-hotfix1 adds them; rows marked "NeoForge hotfix" require that build and are not present in the original 2.0.5 jar. The hotfix has not been publicly released.

For shaped recipes, read each grid left to right and top to bottom; `/` separates rows and `·` means an empty slot. Shapeless recipes can be arranged in any order. Stonecutter recipes use one input. Each recipe produces one item unless another amount is shown.

The finish recipes accept the base kit or any listed colored version of the same kit, as supplied by the release item tags. Installed datapacks may change tag membership.
