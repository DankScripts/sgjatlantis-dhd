# Locked Atlantis DHD 2.0.2-beta.1 baseline

This directory preserves the user-accepted Forge 1.20.1 build immediately
before development of synchronized physical DHD constellations and pressed
triangle illumination.

The three artifacts in this directory are immutable reference inputs. Future
build scripts and model generators must write to new versioned output paths and
must not overwrite these files.

Accepted behavior and appearance include the restyled Atlantis table, corrected
Z-shaped supports, teal patterned control crystals, seated round iris control,
UV-safe DHD dialer plate, and clean front corner shadow strip.
