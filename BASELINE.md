# Current NeoForge build baseline

The historical NeoForge 1.21.1 reference JAR had SHA-256
`8A2DAEE132C5D1601B36100466CF43FFFBFD4E04458A24BF1AF096EBC1762135`.

NeoForge builds directly from source; this historical JAR is neither required
for building nor included in the source archive. The obsolete More Gates 4.3.2 bridge was Forge-only
and is absent from this build.
